# SANZAR Brand Identity & Media Kit

Unified **SA Calligraphy** brand system for the **SANZAR** Chinese language learning platform (Web & Android App).

## Color Palette (Luxurious Emerald & Champagne Gold)

| Token | Hex | Usage |
| :--- | :--- | :--- |
| Deep Forest | `#0B1D14` / `#12392A` | Dark surfaces, hero & badge base |
| Luxury Emerald | `#176B4B` / `#0B523B` | Primary brand color, light-mode theme color |
| Imperial Jade | `#247754` / `#19B46B` | Gradient highlight, success accents |
| Champagne Gold | `#C6A46A` / `#F2DFB6` | Luxury rim accent, calligraphic highlight |
| Ivory Cream | `#FFFDF8` / `#F7EDD6` | Calligraphic monogram highlight on emerald |
